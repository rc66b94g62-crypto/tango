# 単語帳

自分専用の単語帳アプリ（iPhone向けWebアプリ）。英単語と漢字の読みを、カードをめくって覚えます。

## できること

- 単語帳を作って分けて管理（英単語／漢字、色分け）
- フォルダで単語帳をまとめる（名前と色を自由に設定、フォルダの中にフォルダも作れる、開閉できる、フォルダごとに学習）
- 4つの出題パターン：英→日、日→英、漢字→読み、読み→漢字
- 一問一答の単語帳（化学の用語・化学式・化学の公式・数学の公式などのひな形、表と裏の名前は自由に設定）。$…$ で囲んだ数式や $\ce{…}$ の化学式をきれいに表示
- 「覚えた」「まだ」で仕分け（ボタン、または左右スワイプ）
- 「すべて学習」と「まだだけ学習」。「まだだけ」は全部覚えるまで繰り返し
- ホームの「今日の復習」で、全単語帳の「まだ」をまとめて復習
- 英単語の読み上げ（漢字は読みを読み上げ）
- 単語の検索
- テキストを貼り付けてカードを一括追加（`表,裏` を1行に1枚）
- バックアップの書き出しと読み込み
- 右上の歯車から設定：めくる動きの種類（横に回転・縦に回転・ふわっと）と長さ、動きのオン／オフ、振動、バックアップ
- オフラインで動作、ダークモード対応

## 単語帳の写真から作る

1. 「カードを追加」の画面で、作り方に合った依頼文の「コピー」を押す（漢字の単語帳では「見出し語から作る」と「例文から作る」を選べる）
2. Claudeなどに単語帳の写真と一緒に送る
3. 返ってきたテキストを貼り付けて追加

「例文から作る」では、例文の中の問われる語を［ ］で囲んだカードができ、学習中はその部分が色付き・下線で表示されます。

## iPhoneへの入れ方

1. Safariでアプリのページを開く
2. 共有メニュー →「ホーム画面に追加」
3. 「Webアプリとして開く」をオンにして「追加」

データはiPhone本体（このアプリ）の中に保存されます。機種変更の前などは、ホーム右上の歯車 →「バックアップを書き出す」で保存してください。

## 更新するとき

`index.html` を変更したら、`sw.js` の `CACHE` の番号（`tango-v1` → `tango-v2`）も上げてください。

## 使っているもの

数式・化学式の表示に [KaTeX](https://katex.org/)（MITライセンス、`vendor/katex/`）を同梱しています。
